Se arrienda el uso de una aplicación web a medida que reemplaza la planilla Excel de cientos de miles de filas: inventario y armado de dosímetros, asignación masiva e individual, trazabilidad, control de despacho, dashboard e informes, y acceso por rol (administrador, operador y ejecutivo). El cliente no administra servidores: el hosting, los respaldos y el mantenimiento van dentro de la cuota.
